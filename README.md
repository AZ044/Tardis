# Tardis Dashboard - Train Delay Prediction

## Description

Interactive dashboard for visualizing train delay distributions and predicting average arrival delays.

The dashboard uses a **Linear Regression** model for predictions. **Decision Tree** and **Random Forest** models are also trained in `tardis_model.ipynb`; the Decision Tree interface is currently disabled in `tardis_dashboard.py`.

---

## Requirements

- Python 3.12+
- pip

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/AZ044/Tardis.git
cd Tardis
```

### 2. Create and activate a virtual environment

```bash
python -m venv tardis
source tardis/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```
> This installs all dependencies at once.

---

## Required Files

Make sure the following files are present in the project directory before running the dashboard:

| File | Description |
|------|-------------|
| `cleaned_dataset.csv` | Cleaned dataset generated by `tardis_eda.ipynb` |
| `linear.pkl` | Trained Linear Regression model |
| `mapping_depart.pkl` | Mapping of departure station names to codes |
| `mapping_arrivee.pkl` | Mapping of arrival station names to codes |

> These files are generated by running `tardis_eda.ipynb` and `tardis_model.ipynb`.
>
> `DecisionTreeRegressor.pkl` and `RandomForest.pkl` are also produced by `tardis_model.ipynb`, but the dashboard does not load them at the moment.

---

## Usage

### 1. Generate the cleaned dataset

Run the notebook `tardis_eda.ipynb` to clean the raw data and generate `cleaned_dataset.csv`.

### 2. Train the models

Run the notebook `tardis_model.ipynb` to train the models and generate the `.pkl` files.

### 3. Launch the dashboard

```bash
streamlit run tardis_dashboard.py
```

The dashboard will open automatically in your browser at `http://localhost:8501`.

---

## Dashboard Features

### Delay Distribution Visualization
- Histogram of average arrival delays
- Filter by month and year using the sidebar sliders

### Descriptive Statistics Panel
- **Average delay**: mean arrival delay for the selected period
- **Total trips**: number of trips in the selected period
- **Punctuality rate**: percentage of trips with less than 5 minutes of delay

### Prediction Interface
- **Linear Model**: predict arrival delay based on departure station, arrival station, trip duration, month and year
- Select journey parameters from the sidebar and click **Predict Linear Model** to get the predicted delay in minutes
